## Procedure

1. Confirm checkout, current role/receipt, relevant requirements, actual code, and affected contracts. This skill does not activate integration or grant shared-file ownership.
2. Trace manual paste, automatic SMS, and selected-chat notifications into one native analyzer. Reject browser-only monitoring and reliance on a hidden WebView, timers, or cloud inference.
3. Keep capture, bounded dispatch, trained inference, contextual policy, native warnings, and UI rendering distinct. Inspect trust/lifecycle boundaries before proposing dependencies.
4. Use the documented stack direction; pin a compatible toolchain at first implementation and record real phone/OS/app prerequisites. Do not imply current runtime support from the proposed stack.
5. Compare any model/runtime change on Filipino/English quality, learned contribution, cold resources, background behavior, security, and timebox. The trained classifier is a baseline, not proven superior or accurate.
6. Integration versions contract/reason/retention changes and decisions; consumers propose rather than race edits. Preserve both automatic modes when cutting optional scope.
7. Define the smallest real capture-plus-analysis slice and measurable evidence. Return decisions, assumptions, affected contracts, actual checks, blockers, and next action through existing self-validate/handoff workflows.

## Review scenarios

`evals/evals.json` contains synthetic read-only behavior scenarios. Evaluate scope, uncertainty,
and compatibility; application tests and model benchmarks are separate. Report actual findings
and missing prerequisites rather than fabricating success or implementing unauthorized changes.
