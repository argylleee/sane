# Figma exports: Surface Pro 8 frames

Source: Figma PNG exports supplied by the product owner on October 9, 2026 (Surface Pro 8 frame size).
These are the visual reference for TASK-206. They show Welcome, Scan, Result (four verdict states) and Learn in
English and Filipino. Taglish and the phone (360 px) layout are not drawn: derive them from the same
components using `DESIGN.md` and `.agents/skills/design-ux/SKILL.md`. Where a frame disagrees with
`RULES.md` (for example anything implying network access, accounts, SMS or monitoring), the rules win.

Files are named `<screen>-<language>[-<state>].png`; numbered `ready-N` frames are Scan variants.
